# Module 2: Prompt Engineering

## What is a Prompt?

A prompt is the input you give to an AI model. Good prompts = good responses.

## The 4 Elements of a Great Prompt

### 1. Role
Tell the AI who to be.
You are an expert Python developer...
You are a patient math tutor...

### 2. Context
Give background information.
I'm a beginner learning programming...
I'm preparing for a job interview...

### 3. Task
Be specific about what you want.
Write a function that sorts a list...
Explain neural networks in simple terms...

### 4. Format
Specify the output format.
Respond in Amharic...
Use bullet points...
Show code with comments...

## Prompt Patterns

### Chain of Thought
First...

Then...

Finally...

### Few-Shot Learning

## Ethiopian Context Tips

When building prompts for Ethiopian users:
- Use Amharic/English code-switching naturally
- Reference local examples (Coffee ceremony, Habesha culture)
- Be respectful of cultural values
