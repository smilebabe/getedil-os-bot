## Building Your First AI App

Use Groq's free API to build a simple Q&A bot.

Steps:
1. Get API key from console.groq.com
2. Install groq-sdk: pip install groq
3. Write code to send prompts and display responses
4. Add error handling and system prompts
5. Deploy on Render (free tier)
